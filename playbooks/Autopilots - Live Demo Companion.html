03 · Locked-Down Networking

Foundry Stays Private; Only Activity Protocol Is Reachable

Microsoft 365 needs a public door for Activity Protocol. In both options, publicNetworkAccess=Disabled stays intact for everything else.

When to choose Option A

Simplest footprint: Microsoft filters source ranges and enforces Entra auth on the activity route only. No public proxy to operate.

When to choose Option B

Enterprise inspection & governance: keep the flag off and terminate at your own YARP + APIM edge with custom policies and logging.

04 · Access Control & Blast Radius

Effective Access = Admin Consent ∩ Resource Permissions

Consenting to MCP scopes lets the autopilot try; SharePoint, Mail, and Teams ACLs decide what actually succeeds.

Trap to Fix First

Exclude from "All Staff"

Agent users are userType = Member, so dynamic "All Staff" groups match them automatically and inherit overshared write access.

Fix: add agentIdentityBlueprintId -eq null to dynamic group rules and run an oversharing sweep before hiring.

Time-Bound Grants

Use Access Packages

Grant only the specific sites, channels, or datasets the team workflow requires via Entra Access Packages with an expiry date.

Result: the sponsor must renew access; if nobody renews, permissions lapse automatically without touching consent.

Safe Rollout

Start Draft-Only

Separate reading from publishing. Let the autopilot read source data under its own grant and produce drafts.

Result: a human reviews and sends or publishes the final artifact — zero accidental external emails or edits.
